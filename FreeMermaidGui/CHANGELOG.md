# Changelog

## 1.0.0 - 2026-08-13

First release.

- Canvas editor for nine node-and-edge diagram types
- Row editors for thirteen data and sequence oriented types
- Source mode with live rendering for six further types plus free-form paste
- Flowchart source parses back onto the canvas, including shapes, link styles, subgraphs, styling, classes and click links
- Undo and redo, multi-select, grouping, duplication, snap to grid, zoom, automatic layering
- PNG, SVG and .mmd export; .mmd import with diagram type detection
